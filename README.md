# Kalendar Mita

Веб-приложение календаря, разработанное на React.

Проект представляет собой клиентское приложение с пользовательским интерфейсом для работы с календарём.

## Технологии

* React
* JavaScript
* HTML
* CSS
* Create React App

## Структура проекта

```text
kalendar_Mita/
├── public/              # Статические файлы
├── src/                 # Исходный код приложения
├── package.json         # Зависимости и npm-скрипты
├── package-lock.json
└── README.md
```

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/dalzhin1isp23/kalendar_Mita.git
```

Перейдите в папку проекта:

```bash
cd kalendar_Mita
```

Установите зависимости:

```bash
npm install
```

## Запуск

Запустите приложение в режиме разработки:

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```

## Сборка

Для создания production-сборки:

```bash
npm run build
```
